# 06 · Менше напівжирного

Гілка: `fix/emphasis-weights`. Знахідка рев'ю F07. Лише фронтенд.
Закриває `DESIGN_PRINCIPLES.md` §5 («Значення важчі за підписи»).

## Що зараз

Коли жирне все — не виділено нічого:
```
probe-perception.emphasis.proportionBold (mobile-390):
  тренування 65 % · розклад 56 % · журнал 55 %   ← ієрархія не читається
  Програми 32 % · Прогрес 20 %                   ← читається
```

Джерела напівжирного:
- `styles/index.css` → `.btn { … font-semibold … }` (усі кнопки, зокрема ghost «Прибрати», «+ підхід»)
  і `.badge { … font-semibold }`;
- `TryMoreStatusBadge`: «✓ Прогрес», «Час додати вагу» — `font-semibold`;
- `SchedulePage.tsx` (~рядок 117): невибрані дні — `font-semibold`, вибрані — `font-bold`;
- журнал: заголовки груп `font-bold uppercase` (~рядок 164), лічильник «Спробуй більше» `font-bold`.

## Що зробити

1. Semibold лишити **значенням** (вага, повторення, назва вправи), основній кнопці й заголовкам.
2. `.btn-ghost` і `.btn-secondary` → `font-medium`; `.btn-primary` лишається `font-semibold`.
   (Перевірити, що `.btn` розбивається без дублювання — напр. `font-medium` у `.btn`,
   `font-semibold` у `.btn-primary`.)
3. `.badge` → `font-medium`. Статуси «✓ Прогрес» / «Час додати вагу» — `font-medium` + колір
   (колір і ✓ уже несуть сигнал, §4).
4. Розклад: невибрані дні — `font-normal`/`font-medium`, вибрані — `font-semibold`.
5. Ваги — лише 400/500/600/700 зі шкали §5. Якщо додається 500 (`font-medium`) — оновити §5
   (зараз там «400, 600, 700») і `index.html` уже вантажить Inter 500.

## Перевірка

- `probe-perception.emphasis.proportionBold` на тренуванні, журналі й розкладі ≤ 35 %.
- Squint-тест знімків до/після: на тренуванні першим читається вага × повторення, а не кнопки.
- Нічого не стало нечитабельним на темному фоні (контраст не змінюється, змінюється лише вага).
- `npm run build`.
