# Дизайн-рев'ю MyGym: план виправлень

Завдання для Claude Code за результатами дизайн-рев'ю від 2026-10-26. Кожен файл — окреме
самодостатнє завдання. Щоб виконати, відкрий новий чат Claude Code в корені репо і напиши
«виконай docs/design-review/0X-….md» (або `/feature` + вміст файлу).

- **Повний звіт** з вердиктом, оцінками, доказами і скриншотами — `REVIEW-2026-10-26.md`
  у цій папці, знімки — у `shots/`.
- Номери «F01…F14» у завданнях посилаються на звіт.
- **Прод-рев'ю** `PROD-REVIEW-2026-10-26.md` (тир B, реальний акаунт, лише читання): звірка F01–F14
  з продом і нові знахідки P01–P05, що видно тільки на проді (стиснення, застарілий бандл у
  відкритій вкладці, довжина українських рядків). Знімки — `shots/prod-*`.
- Стандарт — `DESIGN_PRINCIPLES.md` у корені. У кожному завданні вказано пункт, який воно
  закриває. Якщо завдання **суперечить** пункту з позначкою [рішення], воно позначене
  «рішення користувача». Тоді спершу змінюється правило, потім код.

> Рев'ю робилось у локальному dev-стеку (http://localhost:5173) на тестовому акаунті:
> 21 тренування, програми А/Б, одне тренування триває. Емуляція — Playwright, тир A:
> мобайл 390×844 (isMobile, touch, DPR 3) і десктоп 1440×900, темна тема, локаль `uk`.
> Не перевірялись: запис тренування від старту до кінця з реальним вводом, клавіатурна
> навігація, повільна мережа, справжній телефон (список — у звіті, «Перевірити на реальному
> телефоні»).

## Дрібниці (без окремих файлів, брати при нагоді)

- **Світла схема.** Застосунок не реагує на `prefers-color-scheme: light`. Це свідомо (§2: лише
  темна тема), але `<meta name="color-scheme" content="dark">` в `index.html` прибере білий спалах
  нативних контролів (date picker) на світлій системі.
- **Дата в `<input type="date">`.** У Chromium з `uk-UA` показала `10/25/2026`. На справжньому
  телефоні з українською системою має бути `25.10.2026` — перевірити, перш ніж лагодити (поле
  форматує браузер, не ми). Перетинається з ux-audit, дрібниця 17.
- **React Query Devtools** у dev перекриває правий нижній кут. Після завдання 5 (нижня панель)
  перенести кнопку devtools у `buttonPosition="top-right"`, щоб не заважала перевіряти панель.
- **«р..» на Розкладі** (прод-рев'ю P04). «Підключено 22 жовтня 2026 р.. Зміни…»: ключ
  `connectedAt` в `uk.json` ставить крапку після `{{date}}`, а дата в `uk` уже закінчується на «р.».
  Перебудувати речення, щоб дата не стояла в кінці.
- **502 на `/api/auth/refresh`** (прод-рев'ю P05) — один раз, імовірно під час деплою; сесія не
  злетіла. Спостерігати; пов'язано з відомою прогалиною `deploy.yml` (не чекає, поки контейнери
  піднімуться).
