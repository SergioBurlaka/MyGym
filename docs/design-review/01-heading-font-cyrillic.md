# 01 · Заголовковий шрифт з кирилицею

Гілка: `fix/heading-font-cyrillic`. Знахідка рев'ю F01. Лише фронтенд.
**Рішення користувача:** змінює [рішення] `DESIGN_PRINCIPLES.md` §2 («Заголовки `h1–h3` —
Bebas Neue… Третіх шрифтів не додаємо»).

## Що зараз

`frontend/tailwind.config.js` → `fontFamily.display: ['"Bebas Neue"', 'system-ui', 'sans-serif']`,
`styles/index.css` → `h1, h2, h3 { @apply font-display tracking-wide; }`, шрифт вантажиться в
`index.html` (Google Fonts, `family=Bebas+Neue&family=Inter…`).

У Bebas Neue **нема кирилиці**. Тому в українській локалі:
- «Журнал тренувань», «Програми», «Прогрес по вправах», назви вправ у картках падають на
  `system-ui` (Segoe UI / Roboto);
- цифри й латиниця лишаються в Bebas Neue, тож в одному рядку змішуються два шрифти:
  «**25** жовтня», «ЖОВТЕНЬ **2026** Р.»;
- «Журнал тренувань» (30 px) на 390 px переноситься у два рядки — підмінний шрифт ширший.

```
probe-craft.typeScale.families: Inter 95 %, Bebas Neue 5 % (лише латиниця й цифри)
```

Чому це важливо: конденсований гротеск — голос бренду (логотип «Сходинка» — Barlow Condensed 800).
Користувач і основна аудиторія — україномовні, тобто «фірмовий» шрифт фактично не видно ніде.

## Що зробити

1. **Спершу спитати користувача** з прев'ю 2–3 варіантів на реальних заголовках (uk + en):
   - **Barlow Condensed** 700 — той самий шрифт, що в логотипі (кирилиця є). Тоді це не «третій
     шрифт», а заміна другого на шрифт бренду. *Рекомендований.*
   - **Oswald** 500–600 — найближчий до Bebas за характером, кирилиця є.
   - **Roboto Condensed** 700 — нейтральніший.
2. Замінити `family=Bebas+Neue` в `index.html` на вибраний шрифт з потрібними вагами й
   `subset`, що включає кирилицю (Google Fonts віддає `cyrillic` автоматично за `unicode-range`).
3. `fontFamily.display` у Tailwind → новий шрифт, fallback `system-ui`.
4. `tracking-wide` у `h1, h2, h3`: для Barlow/Oswald, ймовірно, `tracking-normal` або
   `tracking-[0.01em]` — підібрати на око, звірити з логотипом у хедері.
5. Перевірити всі місця з `font-display` / `h1–h3`: календар (місяць), дата картки журналу,
   великі числа на Прогресі — чи не зламалась висота рядка й вирівнювання.
6. Оновити `DESIGN_PRINCIPLES.md` §2 (правило) і, якщо змінюється шрифт, згадку в `CLAUDE.md`.

## Перевірка

- uk і en на 375 і 1440: у жодному заголовку не змішуються два шрифти (DevTools → Computed →
  Rendered fonts показує один шрифт на весь рядок).
- «Журнал тренувань» на 375 px — в один рядок.
- Мережа: шрифт вантажиться один раз, `display=swap`, немає FOIT на повільній мережі (Slow 3G).
- `npm run build` без помилок.
