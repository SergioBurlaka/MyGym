# 08 · Порожній журнал нового користувача

Гілка: `feat/empty-journal-onboarding`. Знахідка рев'ю F10. Лише фронтенд.
Закриває `DESIGN_PRINCIPLES.md` §11 («Порожній стан пояснює, що тут буде, і дає одну дію»).

## Що зараз

Знімок `shots/empty-journal__mobile-390.jpg` — акаунт без тренувань і без програм:
- `ConsistencyCalendar` на пів екрана — 16 тижнів порожніх клітинок;
- під ним `dashboard.emptyJournal` (`DashboardPage.tsx` рядки 111 і 161) — сірий рядок
  «Ще немає жодного тренування. Натисніть «Нове тренування»…», тобто посилає до кнопки
  **вище**, за календарем;
- про Програми (єдиний спосіб для нового користувача стартувати з готового набору вправ —
  CLAUDE.md, «Програми») ні слова.

## Що зробити

1. Якщо тренувань **нема зовсім** (`total === 0` з `useWorkoutsQuery`, не лише на поточній
   сторінці) — календар не показувати.
2. Замість нього картка «З чого почати» (`components/JournalEmptyState.tsx`):
   - «1. Створи програму — набір вправ, який повторюєш (напр. А і Б через раз)» → кнопка
     «+ Програма» (`/programs`, одразу відкрита форма, якщо це просто — інакше просто сторінка);
   - «2. Почни тренування й запиши підходи — наступного разу вага й повторення підставляться
     самі» → «+ Тренування» (той самий `NewWorkoutButton`).
   Одна `btn-primary` (§7): якщо програм нема — «+ Програма», якщо вже є — «+ Тренування».
3. Коли програма є, а тренувань нема — картка лише з кроком 2.
4. i18n en/uk (`dashboard.onboarding.*`), прибрати `dashboard.emptyJournal`, якщо ніде більше
   не потрібен.

## Перевірка

- Новий акаунт (dev, реєстрація): журнал без календаря, картка з двома кроками, кнопка веде на
  Програми.
- Створити програму → повернутись: лише крок 2, основна кнопка — «+ Тренування».
- Перше тренування → журнал звичайний, з календарем.
- `npm run build`, парність i18n.
