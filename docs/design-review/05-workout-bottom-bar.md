# 05 · Сторінка тренування: нижня панель, меню «⋯», один статус

Гілка: `feat/workout-bottom-bar`. Знахідки рев'ю F05, F11 (і ux-audit, дрібниця 18). Лише фронтенд.
Закриває `DESIGN_PRINCIPLES.md` §7 (одна основна дія, вимкнена основна — не тьмяний акцент,
деструктивне — не поруч з основною) і §8 (основні дії в нижній зоні, `safe-area-inset-bottom`).

## Що зараз

`pages/WorkoutFormPage.tsx`, шапка над першою вправою (~рядки 440–495):
`[Зберегти як програму] [Видалити] [Завершити тренування] [Зберегти]`.

- На тренуванні з 5 вправами сторінка ≈ 5 екранів — щоб завершити, треба прогорнути вгору.
  `probe-heuristics.fitts`: дії «top of screen, requires regripping».
- «Видалити» (`btn-secondary`) виглядає так само, як «Зберегти як програму», і стоїть поруч.
- «Зберегти» — `btn-primary`, але через автозбереження вимкнена більшість часу:
  `disabled:opacity-50` → тьмяно-помаранчева кнопка як звичайний стан (§7).
- **F11.** На кожній вправі одночасно два статуси прогресу: `ProgressionBadge` (~рядок 522,
  «Прогрес у нормі») і шкала `TryMoreStatusBadge` («✓ Прогрес» / «ще 3 тренування…»).
  На десктопі «Прогрес у нормі» стоїть поряд із «✓ Прогрес» над тією самою вправою.
  «Прибрати» (вправу, ~рядок 530) на телефоні — окремий червоний рядок між бейджем і відліком.

## Що зробити

1. **Липка нижня панель** (`fixed bottom-0`, `pb-[max(0.75rem,env(safe-area-inset-bottom))]`,
   фон `surface-raised` + верхня рамка):
   - ліворуч — статус збереження: «Збережено ✓» / «Зберігаємо…» / «Не вдалося зберегти ·
     Повторити» (замість окремого банера або разом з ним — вирішити);
   - праворуч — одна `btn-primary` «Завершити» (для завершеного тренування — панель не
     показувати або лише статус).
   `<main>` отримує нижній відступ на висоту панелі, щоб остання вправа не ховалась.
2. **Прибрати кнопку «Зберегти».** Явне збереження лишається через «Завершити» і вихід зі
   сторінки (cleanup уже зберігає). Перевірити, що `workout.emptySetError` (зараз показується
   на явне «Зберегти»/«Завершити») усе ще досяжний через «Завершити».
3. **Меню «⋯»** біля дати: «Зберегти як програму» (поповер з полем назви лишається, лише
   відкривається з меню), «Видалити тренування» — червоним, з підтвердженням як зараз.
   Disclosure-патерн як у `ProfileMenu`/`NewWorkoutButton` (Escape, `aria-expanded`, ux-audit 01).
4. **Один статус на вправі (F11).** `ProgressionBadge` на сторінці тренування показувати лише
   для `increase_weight` / `start_adding_weight` («Час додати вагу») — те, чого шкала не каже.
   `ok` / `try_more` / `no_data` — не показувати (шкала вже це каже, і живіше — «після цього
   тренування»).
5. «Прибрати вправу» → у «⋯» картки вправи (той самий компонент меню), не окремим рядком.
6. Вимкнений стан основної кнопки (§7): `.btn-primary:disabled` — `bg-surface-border
   text-slate-400`, а не `opacity-50`. Глобальна зміна — перевірити інші сторінки.

## Перевірка

- Мобайл 375, тренування з 5 вправами: «Завершити» видно на будь-якій позиції скролу; остання
  вправа не перекрита панеллю.
- Клавіатура відкрита на полі нижньої вправи — панель не перекриває поле (Android Chrome;
  iOS — у списку «перевірити на телефоні»).
- Статус: правка → «Зберігаємо…» → «Збережено ✓»; офлайн → «Не вдалося зберегти».
- На вправі один статус; «Час додати вагу» досі видно, коли бекенд його пропонує.
- Меню «⋯»: Escape закриває, фокус повертається на кнопку.
- `npm run build`, парність i18n.
