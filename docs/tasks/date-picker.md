## 0. Проблема

У шапці `WorkoutFormPage.tsx` дата — нативний `<input type="date" max={todayIso}>`. На Android він відкриває системний діалог (біла картка, синій акцент, «Установити / Скасувати / Очистити»), який не схожий на MyGym, без анімації і без жодного контексту (не видно, в які дні вже були тренування). Крім того:

- `max={todayIso}` забороняє майбутні дати — **користувач хоче будь-яку дату**, обмеження прибрати;
- `todayIso = new Date().toISOString().slice(0, 10)` — це дата в **UTC**, а не локальна: у Львові з 00:00 до 02:00 (03:00 влітку) «сьогодні» — ще вчорашній день. Рахувати локальну дату.

Референс поведінки й анатомії — Ant Design Calendar / DatePicker (https://ant.design/components/calendar). Бібліотеку **не** підключаємо (у фронтенді нема antd, тягнути її заради одного пікера — зайве), робимо власний компонент.

## 1. Компонент `frontend/src/components/DatePicker.tsx`

```ts
type DatePickerProps = {
  value: string;                 // 'YYYY-MM-DD'
  onChange: (iso: string) => void;
  ariaLabel: string;             // t('workout.dateLabel')
  markedDates?: Set<string>;     // дні з тренуваннями → крапка
};
```

- **Тригер** — кнопка, як у макеті: іконка календаря, «28 жовт. 2026, ср», шеврон (повертається на 180° при відкритті). `aria-haspopup="dialog"`, `aria-expanded`, `aria-label` з повною датою («Дата тренування: 28 жовтня 2026. Змінити»). Висота 44 px; рамка `accent`, коли відкрито.
- **Поповер** під тригером на всю ширину контенту (16 px відступи), `role="dialog"`, підкладка-затемнення `rgba(8,10,14,.55)` по всьому екрану; тап по підкладці закриває.
- **Обмежень дат нема**: будь-який день, місяць, рік — у минулому й майбутньому.

## 2. Анатомія (з Ant Design)

- **Шапка панелі:** `«` рік назад · `‹` місяць назад · «Жовтень» · «2026» · `›` місяць вперед · `»` рік вперед. Кнопки 40×44, кругова кнопка ≥ 44 по висоті.
- **Режими панелі (як `mode` в Ant):** `date` → тап на назву місяця → `month` (сітка 3×4 «січ. … груд.»); тап на рік → `year` (десятиліття 3×4, крайні роки приглушені, `«»` гортають на 10 років). Вибір у `year` → `month` → `date`.
- **Сітка днів:** 6 тижнів × 7, тиждень з **понеділка**, заголовки «Пн … Нд» (`<abbr title="понеділок">`), вихідні трохи тьмяніші. Дні сусідніх місяців — `hint` `#828a99`, клікабельні (перехід на той місяць).
- **Стани клітинки:** сьогодні — рамка 1 px `accent`, жирний; вибраний — заливка `accent`, текст `text-surface` (DESIGN_PRINCIPLES: на помаранчевому — темний текст); є тренування — крапка 4 px під числом (`accent`, на вибраному — темна). Клітинка 46 px висотою, візуальний квадрат 38×38, радіус 10.
- **Футер:** чіпи «Сьогодні» (акцентний) і «Вчора», праворуч легенда «• є тренування».
- Вибір дня **одразу** застосовує дату (як Ant без `showTime`) і закриває поповер через ~180 мс, щоб було видно «підстрибування» вибраної клітинки. Кнопок «Установити / Скасувати / Очистити» нема — дата тренування обов'язкова, скасування = тап поза поповером / Esc.

## 3. Анімації

Таймінги — з Ant (`motion-slide-up`, `zoom-big`), значення в макеті:

| Що | Анімація | Тривалість, easing |
|---|---|---|
| Відкриття поповера | `opacity 0→1`, `scaleY .8→1`, `transform-origin: top` | 200 мс, `cubic-bezier(.23,1,.32,1)` |
| Закриття | навпаки | 160 мс, `cubic-bezier(.755,.05,.855,.06)` |
| Підкладка | fade in / out | 200 / 160 мс |
| Зміна місяця | сітка `translateX(±18px)→0` + fade, напрямок за стрілкою | 220 мс, `cubic-bezier(.23,1,.32,1)` |
| Зміна режиму (день/місяць/рік) | `scale .92→1` + fade | 200 мс, `cubic-bezier(.08,.82,.17,1)` |
| Вибраний день | «pop» `scale .6→1.08→1` | 280 мс, `cubic-bezier(.34,1.56,.64,1)` |
| Шеврон тригера | `rotate(180deg)` | 200 мс |

- Закриття: стан `closing` → клас вихідної анімації → розмонтування після `animationend` (не таймером «на око»).
- Перезапуск анімації сітки при гортанні — через `key={`${y}-${m}`}` на контейнері.
- `@media (prefers-reduced-motion: reduce)` — анімації вимкнено (DESIGN_PRINCIPLES, рев'ю F10).
- Keyframes — у `tailwind.config` (`keyframes`/`animation`), не інлайн-стилями.

## 4. Доступність і клавіатура

- Фокус при відкритті — на вибраний день; при закритті — назад на тригер. Фокус не виходить з діалогу (Tab циклічно).
- Стрілки ←→↑↓ — день / тиждень (з переходом місяця), `PageUp/PageDown` — місяць, `Shift+PageUp/PageDown` — рік, `Home/End` — початок/кінець тижня, `Enter/Space` — вибрати, `Esc` — закрити. Обробник `keydown` — на діалозі, не глобальний (як у `Popconfirm`, але в межах компонента).
- Клітинка: `<button aria-label="28 жовтня 2026, середа, є тренування" aria-pressed>`; сьогодні — `aria-current="date"`; заголовок місяця — `aria-live="polite"`.
- `:focus-visible` кільце `accent`; контраст тексту ≥ 4.5:1 (у макеті перевірені `#e9ecf2`, `#9aa2b1`, `#828a99` на `#1d222c`).

## 5. Дані, i18n, інтеграція

- **Назви місяців/днів — через `Intl.DateTimeFormat(i18n.language)`** (`month: 'long'`, `'short'`, `weekday: 'short'`), щоб працювали і `uk`, і `en`; підписи кнопок («Сьогодні», «Вчора», «Попередній місяць», «є тренування»…) — нові ключі `datePicker.*` в `en.json` і `uk.json` (звірити скриптом ключі).
- **Крапки тренувань** — `useWorkoutDatesQuery(from, to)` на видимі 6 тижнів (сусідні місяці кешуються react-query); поточне тренування теж має крапку.
- Утиліти дат (локальна `todayIso`, `addDays`, `startOfWeekMonday`) — в `utils/date.ts` з юніт-тестами; не через `toISOString()`.
- `WorkoutFormPage.tsx`: замінити `<label>…<input type="date">…</label>` на `<DatePicker value={dateDraft} onChange={commitDate} …/>`; **прибрати `max={todayIso}`**. Бекенд (`workouts.schema.ts`) обмежень на дату не має — лишається як є.
- Кольори: у макеті акцент `#ff6b2c`, токен `accent` — `#ff5a36`; за `design/README.md` береться **токен**, розбіжність згадати в PR.

## 6. Тести

- Юніт `utils/date.ts`: сітка місяця починається з понеділка (жовтень 2026 → 28.09), перехід грудень→січень, локальна «сьогодні» о 00:30 за Києвом.
- Компонентно / вручну в dev-стеку (`tester`), телефон 375 px: відкриття/закриття з анімацією, гортання місяців/років, режими місяць/рік, «Сьогодні»/«Вчора», вибір майбутньої дати зберігається (PATCH `/workouts/:id`), клавіатура, `prefers-reduced-motion`.
