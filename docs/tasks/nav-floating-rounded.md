## 0. Що зараз (`components/BottomNav.tsx`)

`fixed inset-x-0 bottom-0 … rounded-t-[24px] border border-b-0 border-surface-border bg-surface`, бокові відступи `max(8px, inset)`, `pt-1`, `paddingBottom: 8px + inset`, висота `--bottom-nav-h` (70px) + inset; тінь `shadow-nav-panel` (`0 -14px 36px rgba(0,0,0,0.9), …`) — на телефоні затемнює нижню вправу картки (скріни 2026-11-07).

## 1. Що змінити (артборд M9)

1. **Плаває над низом екрана:** відступ **6 px від низу і з боків** — `left/right: max(6px, env(safe-area-inset-left/right))`, `bottom: calc(6px + env(safe-area-inset-bottom))`. Home-indicator inset тепер іде у **відступ панелі від низу**, а не у внутрішній `paddingBottom`.
2. **Заокруглена з усіх боків:** `rounded-[24px]` (замість `rounded-t-[24px]`).
3. **Рамка по всьому контуру:** `border border-surface-border` (прибрати `border-b-0`).
4. **Внутрішні відступи рівні:** **4 px зверху й знизу, 6 px з боків** (`py-1 px-1.5`) — іконки рівно посередині по вертикалі. Без inset усередині.
5. **Висота панелі — 66 px** (рамка 2 + відступи 4+4 + вкладка 56), фіксована, без inset.
6. **`--bottom-nav-h` → 72px** = панель 66 + зазор знизу 6. Inset додається як і зараз (`App.tsx` — `pb` для `<main>`; `ProgramsPage.tsx` — липка панель; шторка «Додатково» — `var + 8px + inset`). Перевірити, що всі три місця дають правильний результат.
7. **Легка тінь** — оновити токен `boxShadow.nav-panel` у `tailwind.config`:
   `0 -6px 16px rgba(0,0,0,0.35), 0 -1px 3px rgba(0,0,0,0.25), inset 0 1px 0 rgba(255,255,255,0.07)`.
   `nav-panel-open` (лише відблиск, коли шторка відкрита) — без змін. Коментар біля токена оновити.
8. **Розмір артборда в макеті** (`width: 371px` / `387px` у корені, `width: 342px` у хедері) — артефакт ручного редагування канвасу, **не брати**.

### Наслідки, які треба перевірити
- Під панеллю та з боків (6 px) тепер видно сторінку — це очікувано; контент не має «застрягати» у цій щілині (останній елемент сторінки має прокручуватися повністю вище панелі).
- Затемнення шторки (`fixed inset-0`) уже накриває весь екран, зокрема щілини довкола панелі — лишити.
- Липка панель форми програми (`ProgramsPage.tsx`) стоїть на `var(--bottom-nav-h) + inset` — тепер вона опиниться над зазором і панеллю; подивитись, чи не лишається дивна смужка між ними. Якщо так — запропонувати рішення в плані.
- `focus-visible` кільце на квадраті — без змін, але перевірити, що не обрізається рамкою панелі.
