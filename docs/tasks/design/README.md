Як читати:
- Це не React-код, а формат дизайн-канвасу: `{{hole}}` — значення з `renderVals()` у `<script>` внизу файлу, `<sc-for>` — цикл, `<sc-if>` — умова. Логіка в скрипті — лише для демонстрації в макеті; справжня логіка — з етапу 1.
- Брати звідти **точні стилі** (кольори, розміри, відступи, радіуси) і структуру блоків; переносити на Tailwind і токени з `DESIGN_PRINCIPLES.md`. Якщо колір макета розходиться з токеном — береться токен, розбіжність згадати в PR.
- Ключові значення: фон `#151922`, картка `#1b2029` / рамка `#262c38`, поле `#151922` / рамка `#2a303c`, акцент `#ff6b2c`; плейсхолдер «минулого разу» `#828a99`, «ціль» `#d08561` (обидва ≥ 4.5:1 на фоні поля); кнопки й поля ≥ 44 px, клітинка підходу 52 px, сітка підходів `repeat(4, 1fr)` з `gap 8px`.
- Тексти — українською як у макеті; в i18n додати й англійські.
