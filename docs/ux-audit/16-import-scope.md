# 16 · Імпорт: пункт головного меню, що працює для однієї таблиці

Знахідка раунду 2: N04. **Спершу рішення користувача — до коду.**

## Що зараз

«Імпорт» — п'ятий пункт головного меню в кожного користувача. Але CSV-парсер
(`backend/src/modules/import/`, `.claude/rules/csv-import.md`) **позиційний**: фіксований порядок
колонок оригінальної Google-таблиці автора, не за заголовками. Текст сторінки пояснює формат
через таблицю, якої в нового користувача немає:

```
«Експортуйте вашу таблицю тренувань як CSV … Формат має відповідати вашій оригінальній
таблиці: дата на першому підході, колонки «вправа» + «вага» по кожній вправі.»
```

Будь-який інший CSV дасть порожній або переплутаний імпорт. Для застосунку, розрахованого на
широку аудиторію, це обіцянка, яку продукт не виконує, — і вона на видноті в навігації.

## Варіанти (вибір за користувачем)

- **(а) Сховати з головного меню** в меню профілю (поруч з «Інтеграції»), текст — без
  «вашій оригінальній», + кнопка «Завантажити шаблон CSV» (файл з правильними колонками й
  двома прикладами рядків). Найдешевше: лише фронтенд + статичний файл.
- **(б) Імпорт за заголовками** з попереднім переглядом («знайдено 12 тренувань, 154 підходи,
  3 нові вправи — імпортувати?»). Справжнє рішення для будь-якої таблиці; середній обсяг,
  зачіпає бекенд.
- **(в) Лишити як є**, якщо імпорт — лише для автора: тоді показувати пункт тільки цьому
  акаунту (фіча-прапорець у `users`).

## Що зробити для (а)

3. Текст `import.description` переписати без «вашій оригінальній таблиці».
4. Оновити `.claude/rules/csv-import.md` (де живе пункт меню).
