# 04 · Контраст кнопок і другорядного тексту

Гілка: `fix/contrast-tokens`. Знахідки аудиту 09, 13, 16. Лише фронтенд.

## 1. Білий текст на помаранчевому — 3.10:1 (знахідка 09, WCAG 1.4.3, потрібно 4.5:1)

**Що зараз.** `.btn-primary` у `src/styles/index.css` (~рядок 25):
`bg-accent text-white`, accent = `#ff5a36` (`tailwind.config.js`). Те саме — активний
пункт меню й активна кнопка EN/UA у `Navbar.tsx` / `LanguageSwitcher.tsx`.

```
rgb(255,255,255) on rgb(255,90,54) · 14px/600 → 3.10:1
```

**Що зробити (рекомендовано — бренд не змінюється).** `#ff5a36` — колір логотипа
«Сходинка», тому не міняти фон, а зробити текст темним: `text-surface` (`#14171c`) →
**5.79:1**. На hover (`#ff7452`) контраст ще вищий. Альтернатива, якщо білий текст
принциповий: окремий токен `accent-strong: '#cc3d1a'` для фону кнопок (білий 4.94:1;
сама кнопка на фоні сторінки 3.64:1 — проходить 1.4.11). Спитати користувача, який варіант.

## 2. Другорядний текст slate-500 — 3.43:1 (знахідка 13, WCAG 1.4.3)

**Що зараз.** `text-slate-500` (`rgb(100,116,139)`) — 31 використання в `src/`. Виміряно:

```
пояснення під графіками Progress, 12px, on #1c2028 → 3.43:1
"First time" 12px on #2a2f3a                       → 2.82:1
дні Mon…Sun у календарі, 10px                       → 3.43:1
```

**Що зробити.** Замінити на `text-slate-400` (`rgb(148,163,184)`): 6.37:1 на картці,
5.23:1 на бейджі. Виняток — лише декоративні елементи без змісту (іконка шеврона в
`Select.tsx`, `placeholder:` у `.input` — плейсхолдер не є єдиною підказкою, лишити).
Підписи днів календаря (10px) заодно підняти до 11–12px.

## 3. Підпис осі графіка обрізано (знахідка 16)

**Що зараз.** `ProgressChart.tsx` (~рядок 63) і `WeeklyCategoryChart.tsx` (~рядок 28):
`margin={{ … left: -12 … }}`. На 375 px підпис «12000» починається на 8 px лівіше за SVG —
видно «2000».

**Що зробити.** `left: 0` (або `YAxis width` за довжиною найбільшого значення) і
`tickFormatter` з компактним форматом (`12k` / `12 тис.`) через `Intl.NumberFormat`
з `notation: 'compact'`.

## Перевірка

- DevTools → Accessibility → Contrast на «+ New workout», «Save», активному пункті меню: ≥ 4.5.
- Progress на ширині 375: підпис верхньої поділки осі повністю видно.
- `npm run build` без помилок.
