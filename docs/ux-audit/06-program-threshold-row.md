# 06 · Рядок порогу програми, що ні на що не діє

Гілка: `fix/program-threshold-row`. Знахідка аудиту 03. Лише фронтенд.

## Що зараз

Картка програми в `pages/ProgramsPage.tsx` (~рядки 234–242) показує внизу
`programs.tryMoreAfterWorkoutsBadge`, якщо `program.tryMoreAfterWorkouts != null`.
Але поріг вправи має пріоритет над програмним, і в програмах «А» та «Б» **кожна** вправа
має свій поріг — тож програмне «3» не діє на жодну:

```
GET /api/programs: Б.tryMoreAfterWorkouts = 3
Б.programExercises[*].tryMoreAfterWorkouts = 4, 4, 4, 4, 6, 6   ← жодного null
Картка: "Розведення в нахилі в сторону ×3 · 6 workouts to 'Try more'"
        "'Try more' after 3 workouts without progress"
```

Людина бачить «3», а нагадування приходить на 6-му тренуванні.

## Що зробити

1. На картці показувати рядок програми лише якщо хоча б одна вправа його успадковує
   (`program.programExercises.some(pe => pe.tryMoreAfterWorkouts == null)`).
2. Якщо успадковують не всі — уточнити текст: «“Спробуй більше” після 3 тренувань без
   прогресу — для вправ без власного порогу» (новий ключ в обох словниках).
3. У формі програми (поле `tryMoreAfterWorkoutsLabel`) — підказка під полем, коли кожна
   вправа має власний поріг: «Зараз не діє: у кожної вправи свій поріг».

## Перевірка

Програми «А» і «Б» на проді: нижнього рядка немає. Програма без порогів у вправах —
рядок є і збігається з відліком у вправах.
