# 11 · Дрібні правки: заголовки вкладок, поле файлу, крапка, перемикач мови, регістр

Гілка: `fix/ux-round2-quick-wins`. Знахідки раунду 2: N07, N08, N11, N14, N05
(`docs/ux-audit/AUDIT-2026-11-01.md`). Лише фронтенд і словники.

## 1. Однаковий `<title>` на всіх сторінках (N07, WCAG 2.4.2)

**Що зараз.** `document.title` ніде не змінюється — `grep -rn "document.title" frontend/src` → 0.
Усі маршрути (`/`, `/progress`, `/programs`, `/schedule`, `/workouts/:id` …) мають `MyGym`.

**Що зробити.** Хук `usePageTitle(title?: string)` у `frontend/src/utils/` (або `hooks/`):
`document.title = title ? \`${title} · MyGym\` : 'MyGym'`. Викликати на кожній сторінці з
ключем меню (`nav.journal`, `nav.progress` …). Сторінка тренування — дата й назва:
«30 жовтня · Б · MyGym». Мова змінилась → заголовок перераховується (залежність від `t`).

## 2. Поле файлу на Імпорті без назви (N08, WCAG 4.1.2)

`pages/ImportPage.tsx:33` — `<input type="file">` без `label`/`aria-label`. Додати
`aria-label={t('import.fileLabel')}` («CSV-файл із тренуваннями» / «CSV file with workouts»),
новий ключ в обох словниках.

## 3. Подвійна крапка в «Підключено … р..» (N11)

`components/CalendarSubscription.tsx:10` — `formatConnectedAt` дає «27 жовтня 2026 р.», а
`exercises.calendar.connectedAt` = «Підключено {{date}}. Зміни…» → «р.. Зміни». Прибрати
`year` з опцій (рік очевидний) **або** змінити рядок на «Підключено {{date}} — зміни розкладу…».
Перевірити й англійську: «Connected October 27, 2026.» — там проблеми нема, лишити.

## 4. Перемикач мови «UA» (N14)

`components/LanguageSwitcher.tsx`: «UA» — код країни, мова — `uk`. Підпис «УКР» / «EN»,
`aria-pressed={current === lng}`, `lang={lng}` на кожній кнопці, `aria-label` групи
(«Мова інтерфейсу»). Зона натиску — щонайменше 24×24 (зараз 33×24, ок).

## 5. Регістр «ви» / «ти» (N05)

73 рядки `uk.json` звертаються на «ви», три — на «ти»:

| Ключ | Зараз | Стане |
|---|---|---|
| `programs.emptyState` | «Створи програму — і зможеш стартувати з неї…» | «Створіть програму — і зможете стартувати з неї…» |
| `programs.form.errorExerciseRequired` | «Додай хоча б одну вправу.» | «Додайте хоча б одну вправу.» |
| `progress.charts.oneRepMaxDescription` | «скільки ти теоретично міг(-ла) би підняти…» | «скільки теоретично можна підняти…» (безособово, без гендерної скобки) |

Назву функції «Спробуй більше» **не чіпати** — це бренд. Додати в `DESIGN_PRINCIPLES.md`
(розділ про текст) рядок: «Інтерфейс звертається на „ви“; назви функцій — як є».

## Перевірка

- Вкладка браузера показує назву сторінки; на `/workouts/:id` — дату тренування.
- Дерево доступності: поле файлу має назву.
- `/schedule` з підключеним календарем — одна крапка.
- `grep -nE "\\b(створи|додай|зможеш|ти)\\b" frontend/src/i18n/locales/uk.json` — лише «Спробуй більше».
- Скрипт звірки ключів en/uk зелений, `npm run build` без помилок.
