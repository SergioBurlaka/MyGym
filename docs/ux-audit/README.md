# UX/UI аудит MyGym: план виправлень

Набір завдань для Claude Code за результатами UX/UI аудиту проду від 2026-10-25.
Кожен файл — окреме самодостатнє завдання: відкрий новий чат Claude Code в корені
репо і напиши «виконай docs/ux-audit/0X-….md» (або `/feature` + вміст файлу).

- **Повний звіт з доказами** (виміри, відповіді API, скріншоти-описи): `AUDIT-2026-10-25.md`
  у цій папці. Жива версія з коментарями: https://claude.ai/artifact/Dx2vs9Fqe2Kd2SShzAXtUB
- Номери «знахідка NN» у завданнях посилаються на звіт.

> Аудит робився на проді (my-gym-com.duckdns.org), акаунт користувача, мобільна ширина
> 375×812 як основна, 1366×860 як перевірка, англійська локаль. Не перевірялись:
> запис нового тренування від початку до кінця, онбординг нового користувача,
> українська локаль на живому сайті, реальний телефон.

## Дрібниці (без окремих файлів, брати при нагоді)

- **17 · дати.** Три формати: «October 21 · Wed», «08/10» на осях графіків, «2026-10-21»
  у «Last time» на Progress. Звести до одного через `Intl.DateTimeFormat` з `i18n.language`.
- **18 · основні дії вгорі.** «+ New workout» на y=85 px, «Save» на y=202 px з 812 на
  мобільному — поза зоною великого пальця. Розглянути липку нижню панель на сторінці тренування.
- **19 · кардіо.** «Біг 15 хвилин» заведено як вправу з власною вагою «1–1 reps, step 0.50 kg».
  Окремого типу для кардіо (час/дистанція) немає — рішення користувача, чи потрібен.
- **20 · навігація.** На десктопі «Integrations» лише в меню профілю (у мобільному меню є).
  Кнопки створення: «Add» (вправи), «+ New program», «+ New workout» — звести до одного шаблону.
