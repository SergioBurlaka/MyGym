# Завдання 5: Тижневий обсяг на м'яз

## Мета
Бекенд рахує робочі підходи на кожен м'яз за тиждень (дробово: основний = 1,
допоміжний = 0,5) і порівнює з цільовою смугою; тренер і користувач бачать
«середня дельта — 5 при цілі 12–16».

## Залежності
Завдання 3 (обов'язково). Завдання 1 (`setType`, `rir`) і 4 (`status`) —
бажано; без них рахувати всі підходи завершених/відкритих тренувань.

## Контекст у репо
- `GET /api/progression/volume-by-category?weeks=12` і `WeeklyCategoryChart.tsx`
  — схожа агрегація по ISO-тижнях (взяти за зразок).
- `users.timezone` — межі тижня.
- Модуль `coach` (завдання 2).

## Що зробити

### Бекенд
1. Чиста функція `computeWeeklyMuscleVolume(sets, exerciseMuscles, tz)`:
   ```
   sets[muscle][isoWeek] = Σ weight(exercise, muscle)
     по підходах тренувань зі status <> 'abandoned',
     setType <> 'warmup', reps > 0, (rir IS NULL OR rir <= 4)
   ```
   Повертає `total`, `direct`, `indirect` окремо. Юніт-тести.
2. Цільові смуги: глобальний дефолт `[12, 16]`, верх 20; опційно перевизначення
   на м'яз (`user_muscle_targets` або jsonb у `users` — обрати й пояснити).
3. `GET /api/progression/volume-by-muscle?weeks=8` → по тижнях і м'язах
   `{ total, direct, indirect, band, status }`, `status` = `below | in_range |
   upper | over`; для поточного тижня ще `pace` (прогноз до неділі з
   урахуванням запланованих днів, якщо є завдання 6, інакше лінійно).
4. `coach/summary` додає `weekly[]` (лише м'язи з ненульовим обсягом або в
   розмітці програм) і прапорці: «<м'яз> нижче цілі 3 тижні поспіль»,
   «понад 10 підходів на м'яз за одну сесію».

### MCP
5. Обсяг приходить через `get_training_summary` (окремий інструмент не потрібен).
   В описі: «weekly sets: direct = 1, secondary muscle = 0.5; working set =
   not warm-up and RIR ≤ 4 or unrated».

### Фронтенд
6. Блок «Обсяг за тиждень» на сторінці «Прогрес»: перемикач «‹ 20–26 жовт ›»,
   по рядку на м'яз — горизонтальний bullet (Recharts або власний SVG): фон
   0–12 «нижче цілі», 12–16 «ціль», 16–20 «верх діапазону», маркер > 20;
   смуга — цей тиждень, риска — минулий; сортування «Найбільший дефіцит зверху».
   Статуси текстом: «Нижче цілі» (нейтральний колір, **не червоний**), «У
   цілі», «Верх діапазону», «Понад 20 — перевір відновлення», для поточного
   тижня «Темп: дійде до ~13 до неділі». Тултип: «Груди: 13,5 = 10 прямих +
   7 × ½ допоміжних. Ціль 12–16».
7. Під графіком — таблиця з тими самими числами (доступність).
8. Пам'ятати gotcha: `isAnimationActive={false}` на `<Bar>`.
9. en/uk.
