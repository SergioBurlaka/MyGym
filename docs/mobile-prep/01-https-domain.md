# Завдання 1: HTTPS — ✅ виконано (2026-10-21)

Прод працює на `https://my-gym-com.duckdns.org` (DuckDNS + Let's Encrypt/certbot).
Як це влаштовано — `CLAUDE.md`, розділ «Прод: HTTPS». Що з цього важливо для
мобільного застосунку:

- Refresh-cookie має `secure: request.protocol === 'https'` — на проді прапорець
  `Secure` увімкнувся сам.
- **Домен DuckDNS для Google Play підходить.** Privacy policy, сторінку видалення акаунта
  і API можна розмістити на `*.duckdns.org`. Якщо пізніше перейдеш на власний домен,
  мобільні збірки вже матимуть старий base URL. Тому:
  - старий домен після переїзду не вимикай, а залиш як редірект або другий `server_name`;
  - адресу API в мобільному застосунку тримай у конфігурації збірки, а не в коді.
- **HSTS** зараз `max-age=86400` без `preload` — підняти до року, коли HTTPS стабільний.
- `GET /health` бекенду назовні не проксується (nginx віддає бекенду лише `/api/`,
  `/mcp`, `/.well-known/oauth-*`). Для перевірки після деплою — відкрити
  `https://<домен>/` і залогінитись.
