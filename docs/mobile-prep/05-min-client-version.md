# Завдання 5: Ендпоінт мінімальної версії клієнта (`client-config`)

## Мета
Закласти механізм, який дозволить сервер змусити старі версії мобільного застосунку
оновитися, до того як перша мобільна збірка потрапить до тестерів.

## Навіщо
SPA оновлюється в усіх одразу після деплою, а встановлений APK може бути на кілька
версій старішим. Механізм має бути в першій же мобільній збірці — додати його
пізніше неможливо за визначенням (старі збірки про нього не знатимуть).
Альтернатива — версіонувати маршрути (`/api/v1`) — свідомо відкладаємо: дорожча,
дублює роути; натомість правило «лише адитивні зміни API».

## Що зробити
1. `GET /api/meta/client-config` (публічний, без auth) →
   `{ minSupportedVersion: { android: "x.y.z" }, latestVersion: { android: "x.y.z" } }`.
   Значення — з env (`MOBILE_MIN_VERSION`, `MOBILE_LATEST_VERSION`) з дефолтом `0.0.0`,
   валідація формату semver через Zod при старті (`backend/src/config`).
2. Опційний заголовок `X-Client-Version` (+ `X-Client: mobile`): якщо версія нижча
   за мінімальну — **глобальний** хук повертає 426 зі стабільним кодом `client_update_required`
   на всіх `/api/*`, окрім `/api/meta/*` (щоб старий клієнт міг дізнатися, що треба оновитись). Запити без заголовка (веб) — без змін.
   Порівняння версій — маленька чиста функція (без нової залежності, або обґрунтувати залежність).
3. Переклад `errors.client_update_required` в `en/uk.json`.
4. Тести: client-config віддає значення з env; стара версія → 426; актуальна → 200;
   без заголовка → 200; `/api/meta/client-config` доступний навіть зі старою версією.
5. `.env.example` — нові змінні.
6. CLAUDE.md: новий розділ «Сумісність API з мобільним клієнтом» з правилом
   «лише адитивні зміни: нові поля опційні, поля не видаляються і не змінюють тип;
   ламаюча зміна = підняти `MOBILE_MIN_VERSION`».

## Критерії готовності
- `npm test` + typecheck у `backend/` зелені; веб працює без змін.

## Примітка про MCP / OAuth
Запити MCP-сервера (PAT `mygym_pat_…` чи OAuth `mygym_oat_…`), а також
`/api/oauth/*` і `/.well-known/*` не містять `X-Client: mobile`, тож перевірка версії
їх не стосується. Додай тест: запит з PAT без заголовків версії → 200.
